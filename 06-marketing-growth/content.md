# Content

Source Document استراتژی مستقل Content Marketing تعریف نکرده است. این فایل فقط Content surfaces و رفتارهای Publication که مستقیماً در Source آمده‌اند را ثبت می‌کند.

## Listing content as distributed content

Listing شامل:
- Title
- Description
- Images
- Category
- Category-specific Tags / Attributes

پس از Admin approval می‌تواند در Communication channels منتشر شود.

## Telegram channel content

Source Acquisition strategy:
- انتشار Listingها در Telegram Channel

Admin routing:
- Listingها بر اساس Attribute/Tag به Channel مربوطه ارسال شوند.

Example:
- Ontario + Jobs → Telegram channel مربوطه

## Notification content

Source این Notification contentها را نام می‌برد:
- New listing matching Saved Filter
- Listing performance reports
- Expiry warnings
- Admin message
- Targeted regional/category advertising
- Low Wallet balance
- Early Access lifecycle message

## AI Listing Translation — Future

Future:
- Translate Title

- Translate text attributes/tags
- نمایش Listing بر اساس User language

Source می‌گوید Translation می‌تواند برای Channel publication هم استفاده شود.

Example:
- Toronto Event → translate to English → publish

# Telegram Growth

Telegram مهم‌ترین Growth surface در Source Document است و هم‌زمان Acquisition، Distribution، Notification و Cold-start supply را پوشش می‌دهد.

## Telegram as the main acquisition channel

Source:
- Telegram Group
- Direct link to Mini App
- Listing publication in Telegram Channel
- Notifications

## Version 1.0 role

Version 1.0 شامل:
- Telegram Bot برای Post Listing + View Listing
- Telegram Notifications
- Telegram Crawler Integration برای Initial Supply

## Registration and community membership

پس از Registration:
- Account ایجاد می‌شود.
- Default Province/City انتخاب می‌شود.
- Training/FAQ داده می‌شود.
- Membership در Channel و Group مربوطه اجباری ذکر شده است.
- Coin gift به‌دلیل Phone Verification ذکر شده، اما Amount در همان بخش مشخص نشده است.

## Telegram distribution

پس از Admin approval، Listing می‌تواند در Communication channels منتشر شود.

Admin Channel rules می‌توانند بر Attribute/Tag تکیه کنند.

Example:
- Ontario + Jobs → Telegram channel مربوطه

## Saved Search return loop

User:
1. Filter را در Web App می‌سازد.
2. Telegram notification را فعال می‌کند.
3. Listingهای جدید Matching دریافت می‌کند.
4. Source در یک بخش Daily summary of links را ذکر می‌کند.

Match behavior:
- حدود 70% Filter match می‌تواند Trigger ارسال باشد.

## Telegram Crawler — Cold Start only

Crawler:
- Public Telegram groups/channels را برای Initial Supply استفاده می‌کند.
- Core Platform نیست.
- Structured Data را از طریق API وارد Advertio می‌کند.
- Listingها پیش از انتشار Quality Control می‌شوند.

### Strategic restriction
- Advertio نباید Telegram Search Engine دائمی شود.
- User-generated listings باید خیلی سریع از Crawled listings بیشتر شوند.

### Joined advertiser rule
اگر صاحب Crawled Listing به Advertio join کند:
- Listingهای جدید Crawled او دیگر نباید خودکار ثبت شوند.
- از آن پس User باید Listing را خودش ثبت کند.
- Listingهای قبلی می‌توانند History باقی بمانند.

## Telegram Ads

Source Telegram Ads را در Phase اول Acquisition channel می‌داند.

همچنین:
- User Listing promotion در Telegram Ads برای Future ذکر شده است.

این دو use case متفاوت‌اند:
1. Advertio user acquisition
2. Advertiser listing promotion

## Telegram Stars

Source در Coin purchase به Telegram Stars اشاره می‌کند:
- Version اول: Manual review
- Future: System confirmation

این Payment mechanism است، نه Acquisition channel، اما بخشی از Telegram ecosystem integration محسوب می‌شود.

## Future Telegram-related expansion

- Country/City/Language-specific communication channels
- AI Translation پیش از publication
- Telegram Ads promotion for Listings

## Growth risks

Source Referral بخش احتمال Fake account را مطرح می‌کند:
- User ممکن است Account فیک ایجاد کند.
- Source می‌گوید حتی عضویت آن‌ها در Channel/Group ممکن است در کوتاه‌مدت کمک‌کننده باشد.

این جمله به‌عنوان Observation/idea حفظ شده و Anti-abuse strategy جدیدی از بیرون اضافه نشده است.

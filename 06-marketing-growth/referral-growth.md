# Referral Growth

Referral در Source هم به‌عنوان Acquisition channel و هم Coin incentive مطرح شده است.

## Versioning

Roadmap:
- Referral System در Version 1.5 — Trust Foundation

در بخش Acquisition/Feature prioritization نیز Referral mechanics توصیف شده‌اند.

## User referral link

- هر User Referral link اختصاصی دارد.

## Signup / verification referral rule

Source در Acquisition section:
- هر Registration با Verification
- Referrer و New User هر دو 3 Coins دریافت می‌کنند.

Coin Economy نیز می‌گوید:
- Referral link: 3 Coins برای تازه‌عضو و Referrer

## Package-purchase referral rule

Source یک Flow دیگر تعریف می‌کند:

```text
Invite Friend
→ Friend Purchases Package
→ Both Users Receive Reward
```

Example:
- Both users receive 100 Coins

## Relationship between the two referral rewards

> ⚠️ Source Conflict
>
> یک Rule، Trigger را Registration/Verification و Reward را 3 Coins برای هر دو طرف تعریف می‌کند.
>
> Rule دیگر، Trigger را Friend Purchases Package و Example reward را 100 Coins برای هر دو طرف تعریف می‌کند.
>
> Source مشخص نمی‌کند این‌ها دو Campaign/Stage مستقل، Rewardهای cumulative، یا دو نسخه متفاوت از Referral System هستند.
>
> این مورد نیازمند تصمیم نهایی Product/Business است.

## Growth purpose

Referral در Phase اول یکی از Acquisition sources ذکر شده است.

Source همچنین Bonus Coins را از این منابع می‌داند:
- Initial signup
- Referral Program
- Advertising campaigns
- Discounts

## Abuse / quality caveat

Source احتمال زیر را ثبت می‌کند:
- User می‌تواند Fake account ایجاد کند بدون استفاده واقعی.
- با این حال عضویت آن Accountها در Channel/Group ممکن است در کوتاه‌مدت برای رشد Community کمک کند.

این یک Observation در Source است؛ Validation result یا Final anti-fraud policy برای Referral ارائه نشده است.

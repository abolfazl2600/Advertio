# Distribution

Distribution در Advertio چندکاناله طراحی شده است، اما Availability هر Channel به Version وابسته است.

## Current / early distribution surfaces

Source برای MVP/Version 1.0:
- Web Application
- Telegram Bot
- Telegram Channel / Notifications

MVP واقعی نیز سه Distribution channel داشته است:
1. Website
2. Telegram Bot
3. Specialized Telegram Channel

## Listing publication after approval

Source Listing lifecycle:
- User Listing را تکمیل می‌کند.
- Admin آن را تأیید می‌کند.
- سپس Publication در Communication channelهای مختلف انجام می‌شود.

## Admin channel routing

Admin باید بتواند Rule تعریف کند تا Listing بر اساس:
- Attribute
- Tag
- Province
- City
- Category

به Channel مناسب ارسال شود.

Example:
- Ontario + Jobs → Telegram channel مربوطه

## Translation-aware distribution — Future

## Targeted distribution / broadcast

Source Notification system:
- Targeted advertising به یک City/Region
- انتخاب Userها بر اساس Category / City / Country
- Fee به‌صورت توافقی با Admin

این نوع Distribution با Organic listing channel publication یکسان نیست.

## Crawled listing distribution boundary

Crawled Listing:
- رایگان منتشر می‌شود.
- Monetization Advertio روی آن فعال نیست.
- User مستقیماً به Telegram account Advertiser Redirect می‌شود.

Internal Chat، Review و Escrow برای Crawled Listing فعال نیستند.

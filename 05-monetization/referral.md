# Referral

Referral هم Acquisition mechanism و هم Coin reward mechanism است.

## Roadmap

Referral System در **Version 1.5 — Trust Foundation** ذکر شده است.

## Referral Link

- هر User لینک اختصاصی Referral دارد.
- Referral یکی از کانال‌های جذب فاز اول نیز ذکر شده است.

## Reward Model A — Signup / Verification

Source می‌گوید:
- User جدیدی که با Referral link عضو شود: **3 Coin**
- Referrer: **3 Coin**
- در بخش Acquisition نیز نوشته شده با ثبت‌نام و احراز، هر دو **3 Coin** دریافت می‌کنند.

## Reward Model B — Package Purchase

Flow:

    Invite Friend → Friend Purchases Package → Both Users Receive Reward

Example:
- Both users receive **100 Coin**

این Trigger با Signup reward متفاوت است؛ Source نمی‌گوید یکی جایگزین دیگری است، بنابراین هر دو Rule حفظ می‌شوند.

## Risk / Edge Case

Source احتمال ایجاد Fake Account فقط برای گرفتن Referral signup را مطرح می‌کند.

هم‌زمان اشاره می‌کند که عضویت این Accountها در Channel/Group ممکن است در کوتاه‌مدت برای رشد جامعه کمک‌کننده باشد.

Source Anti-fraud rule مشخصی برای Referral reward تعریف نمی‌کند.

## Wallet Classification

Referral reward در Source از منابع Bonus Coin معرفی شده است.

Bonus Coin rules:
- Expiry دارد.
- قبل از Purchased Coin مصرف می‌شود.
- ممکن است برای بعضی Revenue Serviceها محدود باشد.

See [Wallet](./wallet.md).

## Validation

Source نتیجه واقعی یا Conversion data مشخصی برای Referral Program ارائه نمی‌کند.

# Coin Economy

## Base Definition

Source تعریف می‌کند:

**10 Coin = $1**

Coin/Credit واحد اعتبار داخلی Wallet برای پرداخت Serviceهای Monetization است.

## Coin Acquisition

### Purchased Coins
روش‌های خرید/شارژ ذکرشده:
- Canada bank deposit / transaction verification در شروع
- USDT / Ton
- Telegram Stars
- Iran bank-card / rial deposit
- Coin Packages

جزئیات Current vs Future payment operation در [Wallet](./wallet.md) آمده است.

### Bonus / Reward Coins

Source این Rewardها را ثبت کرده است:

| Trigger | Reward |
|---|---:|
| Video Verification | 5 Coin در یک بخش؛ 3 Coin در Coin Economy |
| National ID verification / mobile match | 10 Coin در یک بخش؛ 3 Coin در Coin Economy و Future |
| Referral signup / verification | 3 Coin برای User جدید + 3 Coin برای Referrer |
| Referral after referred friend purchases a Package | 100 Coin برای هر دو User |
| Review after confirmed deal | 1 Coin |
| Reach 10 deals | 20 Coin + 10 Deals Badge |
| Add each verifiable Social Network | 1 Coin |
| Verified university/work email | 5 Coin |
| Public email | بدون Coin reward |
| Facebook login | 5 Coin در Social Proof Loop |
| Phone verification at registration | Source می‌گوید Gift Coin داده می‌شود، اما مقدار را تعیین نمی‌کند |
| Bank-account verification | مقدار قابل تنظیم در Admin Panel؛ عدد مشخص نیست |

> ⚠️ Source Conflict
>
> Reward مربوط به **Video Verification** در یک بخش 5 Coin و در Coin Economy مقدار 3 Coin ثبت شده است.
>
> این مورد نیازمند تصمیم نهایی Product/Business است.

> ⚠️ Source Conflict
>
> Reward مربوط به **National ID verification** در یک بخش 10 Coin و در Coin Economy مقدار 3 Coin ثبت شده است.
>
> این مورد نیازمند تصمیم نهایی Product/Business است.

### Referral rewards are separate triggers
Source دو Trigger متفاوت را ثبت کرده است و آن‌ها را یکی نکرده است:
- Signup / verification through referral: 3 Coin برای هر طرف
- Friend purchases Package: 100 Coin برای هر طرف

جزئیات در [Referral](./referral.md).

## Coin Consumption

- مشاهده Contact info در Early Access
- Boost
- Extend / Renew
- Repeat/extra Listing rule در همان Category
- Advertiser-sponsored contact cost
- Targeted Bot message بر اساس Region
- Future promotion via Google Ads / Telegram Ads
- Cargo ticket Verification: 20 Coin

- Timeline خود Early Access در Source Conflict دارد.
- See [Early Access](./early-access.md).

## Extend / Renew

Source category-based amounts:
- First 30-day extension:
  - Jobs / Social: 35 Coin
  - Housing: 65 Coin
- Second and later 30-day extension:
  - Jobs / Social: 55 Coin
  - Housing: 85 Coin

See [Extend / Renew](./extend-renew.md).

## Repeat Listing

Source می‌گوید:
- دو Listing رایگان در یک Category ممکن نیست.
- اگر User مجدداً بعد از یک ماه در همان Category Listing ثبت کند، **5 Coin** ذکر شده است.
- بخش دیگری Fee را بر اساس Category متفاوت می‌داند.
- Workflow در صورت وجود Listing فعال User را به Admin/Support هدایت می‌کند.

Source یک Flow نهایی و بدون ابهام برای این موارد ارائه نکرده است.

## Review Reward Rule

- Deal باید توسط هر دو طرف تأیید شود تا Review ممکن شود.
- Userی که Early Access / ارتباط پولی داشته و پس از Deal Review ثبت کند، 1 Coin دریافت می‌کند.
- Reward تکراری برای همان User/Deal قابل انجام نیست.
- Listingهایی که ارتباط رایگان دارند Review دارند، اما طبق Source این Coin reward را دریافت نمی‌کنند.

## Bonus Coin Rules

- Bonus Coin expiry دارد.
- Bonus Coins قبل از Purchased Coins مصرف می‌شوند.
- بعضی Revenue Serviceها ممکن است مصرف Bonus Coin را محدود یا غیرفعال کنند.

## Admin Configurability

Pricing Policy می‌گوید هزینه Serviceها Dynamic است. Rewardهای Verification نیز در بعضی بخش‌ها explicitly قابل تنظیم از Admin Panel توصیف شده‌اند.

See [Pricing](./pricing.md).

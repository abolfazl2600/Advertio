## Revenue loops

### Listing → Message → Payment
- Contact request → 1 Coin Early Access

### Low Response → Boost
- User pays for visibility recovery

### Expire → Extend
- User pays to reactivate Listing

### Deal → Review → Coin
- Review gives 1 Coin → Coin re-enters economy

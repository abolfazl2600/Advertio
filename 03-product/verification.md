# Verification

Verification is the core of Advertio Trust Layer, but Source has multiple Version-scope conflicts. All conflicting definitions are preserved.

## Verification layers

- Phone Verified
- National ID Verified
- Video Verified
- GPS Verified
- Document Verified
- Social Media Verified
- Financial Verified
- Cargo ticket Verified

## Phone Verification

Version 1.0 includes Phone Verification.

Methods/descriptions in Source:
- Telegram message
- Telegram phone-share button
- Mobile OTP

Registration country rule:
- Iran or Canada: accepted
- other countries: Waitlist for Admin approval

## National ID

- only Iran
- mobile number + National ID match
- one section says not available in current Version
- Coin Economy marks it Future

## Video Verification

Workflow:
- video with face movement around 180 degrees
- compare with Profile photo
- manual/operator model described

> ⚠️ Source Conflict

# Advertio — Communication Assets Registry

**Snapshot date:** 2026-10-20 · **Version:** 1.1 · **Maintainer:** Advertio operations (to be assigned)

این پوشه برای ثبت وضعیت فعلی دارایی‌های ارتباطی Advertio ایجاد شده است؛ این اطلاعات **صورت‌وضعیت مشاهده‌شده** هستند و به‌معنای تأیید اتصال فنی، مالکیت یا فعال بودن هر ویژگی در سرور نیستند.

## Files

- [registry.md](registry.md): فهرست کانال‌ها، ربات‌ها، Community، پشتیبانی و ارتباطات تأییدشده/نامشخص.
- [registry.csv](registry.csv): نسخه ساختاریافته برای مدیریت و واردکردن به ابزارهای تحلیلی.
- [flightiranbot24-capabilities.md](flightiranbot24-capabilities.md): بررسی قابلیت‌های موجود در کد ربات FlightIran و تفکیک قابلیت‌های فعال در کد، مشروط و Coming Soon.
- [snapshots/2026-10-20.md](snapshots/2026-10-20.md): شواهد اسکرین‌شات و سوابق اندازه‌گیری.

## قواعد ثبت و نگهداری

1. هر دارایی یک ID پایدار دارد؛ تغییر نام نمایشی یا Username نباید ID داخلی را تغییر دهد.
2. اعداد با **نوع شاخص و تاریخ مشاهده** نگهداری شوند. «۲ monthly users»، «۹٬۲۰۱ subscribers» و «۱۵ chats» قابل‌جمع‌زدن یا جانشینی یکدیگر نیستند.
3. هر ادعا باید با یکی از برچسب‌های **Screenshot observed / Repository verified / User reported / Unknown** قابل ردیابی باشد.
4. بنر «Canada Advertio Community — 15 chats» به معنی اثبات عضویت حقوقی/مدیریتی تمام ۱۵ چت در Advertio نیست.
5. ویژگی‌هایی که در کد یافت می‌شوند الزاماً در استقرار عملیاتیِ فعلی در دسترس نیستند. وضعیت واقعی با تست ربات، لاگ استقرار و داده‌های Telegram تأیید می‌شود.
6. تغییرات بعدی با تاریخ، منبع و توضیح اختلاف از اسنپ‌شات قبلی ثبت شود؛ داده تاریخی حذف نشود.

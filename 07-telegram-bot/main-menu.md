# Main Menu

پس از Registration / Verification، Source برای Telegram Bot این Main Menu را تعریف می‌کند:

- **View Listings**
- **Post Listing**
- **My Profile**
- **My Listings**

## View Listings

User وارد مسیر مشاهده Listingها می‌شود.

جزئیات Source-derived در [Listing Browsing](./listing-browsing.md).

## Post Listing

User وارد Flow ثبت Listing می‌شود:
- Category Selection
- Eligibility Check
- Step-by-step Listing Form
- Preview
- Confirm
- Pending
- Admin Moderation
- Publish

See [Listing Creation](./listing-creation.md).

## My Profile

اطلاعات مرتبط با Profile:
- Base profile
- Verification status
- Last Active
- Deals Count
- Rating / Reviews
- Listing History
- Active Listings

See [User Profile](./user-profile.md).

## My Listings

Source Menu item «My Listings» را صراحتاً تعریف می‌کند.

اطلاعاتی که در Source برای Listingهای User قابل مشاهده/پیگیری هستند:
- Listing status / lifecycle
- Reaching views / Impression-related metrics
- Contact Requests
- Detail Listing View
- Daily Telegram performance notification
- Expiry
- Extend
- Boost
- Post-deal Review flow

Source UI دقیق My Listings را بیشتر از این تعریف نکرده است.

## Wallet Menu

Source در Main Menu ثبت‌شده، گزینه مستقلی با نام Wallet نشان نمی‌دهد.

Wallet Feature در Version 1.1 تعریف شده و Wallet page/actions در بخش مستقل Wallet Document آمده‌اند، اما Source مشخص نمی‌کند که Wallet به‌عنوان Main Menu item در Telegram Bot نمایش داده می‌شود.

جزئیات در [Wallet](./wallet.md).
